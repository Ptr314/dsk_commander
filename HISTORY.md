## [2.0.0]
- [+] Двухпанельный Norton Commander-подобный дизайн.
    - Две равноценные панели со списками файлов.
    - Образ открывается в текущей панели.
    - Управление с клавиатуры в близкой к &laquo;классической&raquo; раскладке клавиш.  
    - Групповые файловые операции между панелями в любых сочетаниях (с учетом доступности записи для отдельных файловых систем).
    - Операции рекурсивного копирования/удаления для директорий. 
    - История просмотра директорий, независимо для каждой панели.
    - Перемещение в корзину (отключаемое) для файлов в хост-системе. 
    - Создание резервных копий (отключаемое) при сохранении DSK.
    - Восстановление удалённых файлов и директорий Apple DOS.
- [~] Исправление ошибок и другие улучшения
    - [~] Проверка несохранённых образов ([#39](../../issues/39)).
    - [~] Сохранение файлов с русскими буквами ([#30](../../issues/30)).
    - [~] Основной компилятор для Windows 10+ заменён на MSVC.
